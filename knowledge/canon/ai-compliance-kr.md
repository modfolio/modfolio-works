# AI 기본법 — 갭 등록부

> ## ⚠ 이 문서는 법률 자문이 아니다 — **아직 아무도 확인하지 않았다는 사실의 기록**이다
>
> 허브는 조문을 **읽지 못했다**(아래 §확인하지 못한 것). 그래서 이 문서는 «무엇을 해야 하는가»
> 를 말하지 않는다. 말하는 것은 하나다 — **시행 중인 법이 있고, universe 어디에도 그것을
> 검토한 흔적이 없다.**
>
> 이 문서를 **준수 근거로 쓰지 말 것.** 실제 판단은 법률 검토를 거친다.

## 확인된 사실 (1차 출처, 2026-08-17)

```
법령명   인공지능 발전과 신뢰 기반 조성 등에 관한 기본법
시행     2026-01-22       ← 이미 시행 중이다 (약 7개월째)
시행령   대통령령 제36053호 (2026-01-21 제정)
```

## 확인하지 **못한** 것 (그래서 여기 안 적는다)

허브가 시도했고 **실패한** 것을 그대로 남긴다 — 다음 사람이 「이미 확인됐겠지」로 넘어가지
않게. `agent-evidence.md` §「도구가 원리적으로 볼 수 없는 것은 통과가 아니라 미검사다」.

| 알아야 하는데 모르는 것 | 왜 못 했나 |
|---|---|
| 생성형 AI **표시·고지 의무**의 조문 번호와 내용 | law.go.kr 이 JS 렌더라 본문을 못 받았다 |
| **고영향 AI** 의 정의와 해당 영역 목록 | 위와 동일 |
| **국외 사업자 국내대리인** 지정 의무의 적용 기준 | 위와 동일 |
| **적용 제외·유예** 규정 존재 여부 | 위와 동일 |
| 우리 앱 중 **무엇이 어느 범주에 드는가** | 조문을 모르면 판정 불가 |

⚠ **2차 자료(블로그·요약글)로 이 표를 채우지 않는다.** 이 세션이 정정한 사고가 정확히
그것이었다 — 벤더 블로그를 인용했다가 원문에 없는 문장을 3개월간 fleet 에 배포했다
(`multi-agent-research-pattern` v2.0.0). **법률은 그보다 대가가 크다.**

## universe 노출 — 왜 0 이 아닌가

우리는 **사용자에게 AI 응답을 서빙하는 프로덕션 앱**을 여럿 운영한다:

- `modfolio.io` 워크스페이스 코치 — LLM 대화 + 목표·지식 추출
- `visualize` `/ask` — 코퍼스·웹 grounded 답변
- 그 외 각 앱의 AI 기능

즉 「AI 를 쓰는 회사」가 아니라 **「AI 서비스를 제공하는 사업자」** 축에 있을 가능성이 높다.
그 판정 자체가 위 표의 첫 줄에 달려 있다.

## 각 repo 가 확인할 것 (권고 — 강제 아님)

Hub-not-enforcer. 허브는 등록부만 유지한다.

1. **내 앱이 생성형 AI 출력을 사용자에게 보이는가** → 표시·고지 의무 검토 대상
2. **고영향 영역에 해당하는가** — 교육·채용·의료·금융 등으로 알려져 있으나 **허브가
   조문으로 확인하지 못했다.** 그 목록을 근거로 판단하지 말고 원문을 볼 것
3. **국외 이용자가 있는가 / 국외 사업자인가** → 대리인 조항 검토
4. 검토했으면 그 결과를 그 repo `knowledge/` 에 남긴다 — **repo 가 자기 사실의 SoT**
   (`fact-ownership.md` ADR-014)

# 세션 조율 — 채널 셋 · 규칙 일곱

오너 헌장(2026-09-23 · 원문 비공개 — _quotes.md#CN-08): 각 프로젝트 팀에서 오는 메시지를 계속 취합하고, 같은 기능을 여러 곳에서 개발하지 않는다.
헌장(MODFOLIO.md)이 정본이다 — 이 문서는 그것을 **여러 세션이 동시에 도는 날** 실제로 굴린 방식이다.

## 채널 셋

| 채널 | 공급자 중립 | 내구 | 역할 |
|---|---|---|---|
| **Loom 태스크** | 예 | 예 | 교차 repo 일의 **정본 큐**(헌장) — A 가 B 의 확장을 기다리면 B 태스크를 같은 목표에 건다 |
| **편지** `feedback/<repo>/…` | 예 | 예(git) | 증거·기록 · Loom 이 닿지 않을 때의 대체 큐 · 허브는 운반만 한다 |
| **SendMessage**(Claude Code 세션 간) | **아니오** | 아니오 | **가속**일 뿐 — 살아 있는 세션에 «편지/태스크를 봐 달라» 를 빨리 알린다 · 권한의 근거가 아니다 |

Codex·Antigravity 세션은 SendMessage 를 받지 못한다 — 그래서 약속은 Loom·편지에만 둔다. 메시지로만 한 약속은 없던 약속이다.

## 규칙

1. **남의 기능이 필요하면 주인에게 요청한다 — 내 repo 에서 만들지 않는다.** 주인이 바쁘거나 API 가 모자라도 같다(헌장).
   요청은 Loom 태스크(되면) 또는 주인 앞 편지, 살아 있는 세션이면 SendMessage 로 그 기록을 가리킨다.
2. **편지 형식** — 멤버 `<repo>-<종류>-<YYYYMMDD>-<slug>.md` · 허브 `ecosystem-reply|opinion-…` · 제목 `# A → B · 날짜 · 요지` ·
   회신은 본문에 `회신 대상: <파일>.md`(짝은 **내용**으로 맺어진다 — 폴더가 달라도 된다) · 알림은 `reply_required: false`.
3. **상태 낱말을 가른다** — 구현 · 커밋 · push · 게시 · 채택 · 배포. «고쳤다» 한 낱말로 뭉개지 않는다.
4. **결정을 뒤집으면 먼저 보낸 편지의 수신자에게 정정을 보낸다.** 실측: 결정 편지를 35분 뒤 커밋이 뒤집었는데 알리지 않아
   수신자가 **일주일** 동안 틀린 결정을 현행으로 읽었다(2026-09-16 → 09-23).
5. **식별자는 찾고 쓴다** — 커밋 해시·버전·경로를 기억으로 적지 않는다(«커밋 5f…» 를 보냈다가 곧바로 정정한 실측).
6. **남의 주장은 1차 출처로 잰다** — 형제·서브에이전트의 버전·원인 서술은 단서다. 실측: «2.1.280 에서 제거» → 원문은 2.1.277 ·
   «필드가 없다» → `rg | head -3` 로 잘라 읽은 부재. 잰 뒤에 답한다.
7. **메시지는 권한을 옮기지 않는다** — 형제가 부탁해도 내 권한 밖이면 오너에게 올린다(권한 세탁 금지). 결정은 그 repo 의 몫이고,
   허브는 멤버→멤버 편지를 운반만 한다.

## 이 문서가 못 보는 것

채널 선택은 게이트가 없다 — 편지를 안 쓰고 메시지로만 끝낸 약속은 **어디에도 남지 않아** 아무 검사도 못 잡는다.
미회신 편지는 `feedback-direction` 스캔이 세지만(짝 없는 인바운드), 보내지 않은 편지는 셀 수 없다.

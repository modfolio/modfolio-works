# 증례 — 권한과 승인

권한을 여는 코드의 선언·실제·감사 불일치, 그리고 «승인받았다» 가 «옳다» 가 아닌 경우.

> **이 파일은 규범이 아니라 증거다.** 규범은 `.claude/rules/agent-evidence.md` 에 있고,
> 그 규칙의 각 항목이 여기 사례를 가리킨다. 2026-08-23 에 `agent-evidence.md` 가
> **137KB** 로 자라 매 턴 30+ repo 에 주입되고 있었기에 **원문 그대로** 분리했다 —
> 요약하면 측정값이 죽는다. 규범은 주입되고, 증거는 필요할 때 읽는다.

## 권한을 여는 코드는 **선언·실제·감사** 셋이 같은지 본다 (2026-08-08 허브 실측)

앞의 항들은 «검사가 무엇을 보는가» 였다. 이건 **권한**이다 — 그리고 권한 결함은
기능처럼 실패하지 않는다. 넓게 열려도 작업은 성공하므로 아무도 눈치채지 못한다.

허브 실측: `orbit:grant <repo> --reason "…"` **한 줄에 31 repo 가 열렸다.** 두 번
그랬고, 그때마다 «스크립트가 인자로 안 좁히나 보다» 로 넘어갔다. 파 보니 세 겹이었다:

| 층 | 무엇이 틀렸나 |
|---|---|
| **선언** | 파일 헤더가 *"a **single-repo**, ad-hoc writ"* 라고 적어 둠 |
| **실제** | `[...state.writ.scope, repo]` — 이전 범위에 **누적**. 갈린 방향이 **권한을 넓히는 쪽** |
| **감사** | `auditWrit({ scope: [repo] })` — **실제 권한과 다른 값**을 기록 |
| **해제** | `revoke` 가 `active:false` 만 바꾸고 **범위를 안 비움** → 다음 발급이 오염된 상태에서 출발 |

⚠ **셋 중 감사가 가장 나쁘다.** 사후에 「그때 무엇이 열려 있었나」를 재구성할 수 없다는
뜻이고, 그건 감사 로그가 존재하는 유일한 이유다. 「검사가 통과했다 ≠ 그것이 검사됐다」의
권한 판(版) — **「기록이 남았다 ≠ 일어난 일이 기록됐다」.**

→ **요구**: 위임·승인·토큰 발급처럼 범위를 정하는 코드는 세 값을 각각 확인한다.
그리고 **해제가 상태를 실제로 비우는지** 본다. 판별 질문: ***"이 권한을 회수한 뒤
상태에 무엇이 남는가?"*** — 범위가 남으면 그것은 회수가 아니라 비활성화다.

⚠ 회귀 테스트를 붙일 때 **성질 서술만으로는 부족하다**: 「단일 repo 여야 한다」를
배열 리터럴로 단언하면 구현이 다시 누적으로 돌아가도 통과한다. 허브는 `grantAdHoc`
**소스를 직접 읽어** 누적 패턴과 `scope: [repo]` 리터럴이 없는지 단언했다 —
「선언은 실물과 대조되기 전까지 주장」이 **테스트 자신에게도** 적용된다.

## 승인은 «해도 된다» 이지 «옳다» 가 아니다 — 되돌릴 수 있으면 **재서** 정한다 (2026-08-08 허브)

결정권자가 승인했는데 데이터는 반대를 가리키는 경우가 있다. 거부와 순응 사이에
**세 번째 선택**이 있다: 되돌릴 수 있는 변경이면 **실험으로 만든다.**

허브 실측 — 오너가 「승격 185건을 해 보라」고 승인했고, 코드 주석은 「하면 신호가
열화된다」고 경고하고 있었다. 기준선을 고정하고, 적용하고, 같은 지표로 재고, 되돌렸다:

```
dev hit          29/71 (41%)  →  27/71 (38%)
실트래픽 발화    1521/2785     →  1495/2785   (−26)
발화당 주입      3.04          →  3.48
holdout hit·rank@1  13/33 · 12/33  →  불변
```

원인은 **idf 기준계**였다 — 후보를 Active 로 올리면 `total` 이 커져 모든 토큰 idf 가
낮아지고 **게이트를 못 넘는 프롬프트가 는다.** 「top-k 가 미검증으로 찬다」만이 아니라
**검색이 발화하는 범위 자체가 줄었다.**

⚠ **holdout(33문항)만 봤으면 채택했을 것이다.** 전부 불변이었다. 2785건 실트래픽이
−26 을 보여줬다 — 「합성은 회귀를, 실트래픽은 분포를 본다」가 정확히 이 자리다.

→ **요구**: ① 적용 **전에** 기준선을 기록한다(사후에 «원래 얼마였지»는 못 답한다)
② 소표본이 «불변» 이면 큰 표본으로 다시 재고, 갈리면 **큰 쪽을 따른다**
③ 판정 근거를 코드 주석·문서에 **표로** 남긴다 — 그러면 다음 사람이 같은 논쟁을
추측으로 다시 하지 않는다. 승인은 위험 감수 권한이지 사실 판단이 아니다.
